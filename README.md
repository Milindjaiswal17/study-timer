# Study Timer

A lightweight, browser-based study timer built with HTML, CSS, and vanilla JavaScript.

## Features

* Start, pause, and resume study sessions
* Reset the current timer
* Save completed study sessions
* View study history
* Daily, weekly, and monthly study statistics
* Delete individual sessions
* Responsive design for desktop and mobile

## Data Storage

Study sessions are stored locally in the browser using `localStorage`.

No backend, database, account, or external server is required. Your study history remains available when you refresh or reopen the website in the same browser and on the same device.

Clearing the website's browser data will remove the saved study history.

## Technologies

* HTML
* CSS
* Vanilla JavaScript
* Browser `localStorage`
